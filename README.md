| Estado en la Base | Significado Operativo y Físico |
| :--- | :--- |
| Activo (Carga) | Vía operativa utilizada exclusivamente para el transporte de carga pesada (forestal, minera, industrial). No hay transporte de pasajeros. |
| Activo (Pasajeros) | Vía operativa utilizada para trenes de pasajeros (servicios rurales o interurbanos), pero sin tráfico de carga pesado continuo. |
| Activo (Pasajeros/Carga) | Vía principal operativa con uso mixto. Circulan de manera regular tanto trenes comerciales de pasajeros como convoyes de carga. |
| Activo (Biotrén / Merval / Melitrén) | Vía operativa de trenes suburbanos eléctricos de alta frecuencia (Biotrén en Concepción, Merval en Valparaíso, o servicios metropolitanos en Santiago). |
| Activo (Carga/Turístico) | Vía operativa destinada principalmente a la carga privada, pero que el Estado utiliza ocasionalmente (fines de semana o verano) para trenes patrimoniales. |
| Inactivo (Sin tráfico en la comuna) | La línea férrea física aún existe intacta (rieles instalados), pero el servicio se suspendió. Ningún tren transita por esa comuna hoy. |
| Inactivo (Tramos levantados) | El servicio está suspendido. La infraestructura férrea existe de forma intermitente: hay sectores con rieles y otros donde la vía fue arrancada o robada (común en la Red Norte). |
| Levantado | El ramal secundario fue clausurado y el Estado ordenó desmantelar y retirar el 100% de la infraestructura (rieles y durmientes) de la comuna. |
